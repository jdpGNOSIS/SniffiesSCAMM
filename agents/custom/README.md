# Custom Agents

Create your own agents here. Each agent is a markdown file with instructions for the AI.

## How to Create an Agent

1. Create a new `.md` file in this folder
2. Use the template below
3. Run it with: `run custom [agent-name]` or `puppet [agent-name]`

## Template

```markdown
# [Agent Name]

## Role
[Describe what this agent does]

## Instructions
[Detailed instructions on how to behave]

## Input
[What input this agent expects]

## Output
[What this agent should produce]

## Constraints
[Rules and limitations]
```

## Available Custom Agents
- `research-analyzer` — Analyzes research data and produces structured insights
- *(Add your own with `create agent [name] [role]`)*
